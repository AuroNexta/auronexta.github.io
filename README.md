# AuroNexta — GitHub Pages
# 
# AuroNexta — Agentic automation, AI/ML, robotics, drones, software & web engineering.
#
# Deploy to GitHub Pages:
#   1. Push to a repository named YOUR_USERNAME.github.io OR
#   2. Push to `gh-pages` branch of any repo
#   3. Settings → Pages → Source: Deploy from branch → gh-pages
#
# Structure:
#   index.html          — Main landing page
#   projects.html       — All projects (unlimited)
#   resume.html         — Team profile viewer (legacy)
#   404.html            — Custom 404 page
#   error.html          — Generic error page
#   maintenance.html    — Maintenance mode page
#   css/style.css       — All styles
#   js/config.js        — Site configuration + demo data
#   js/main.js          — All JavaScript (orbit, modals, forms)
#   mail/send.php       — Contact form SMTP backend
#   AuroNexta_new_logo.png — Brand logo
#
# To connect your GitHub data repo, edit js/config.js:
#   "owner": "YOUR_GITHUB_USERNAME",
#   "repo": "YOUR_REPO_NAME",
#   "branch": "main",
#
# Required repo structure:
#   projects/CLASS_NAME/Project_Name/whitepaper.md (+ cover.png)
#   profile/First_Last_Role.png (+ First_Last_Role.md)
